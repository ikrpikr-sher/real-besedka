## Принцип

Ножки и боковины — плоский лазер из листа. Узор спинки = смена DXF. Трубу почти не используем.

- Лист: Ст3 / оцинк. под порошок, 2.0 или 3.0 мм
- Финиш: RAL 7016 порошок C3
- Дерево: фанера 18–21 мм или массив, болты втулки
- Крепёж: M6/M8 болт + втулка, минимум сварки

## Конвейер

1. DXF раскрой листа (nesting)
2. Лазер 2–3 мм
3. Лёгкая гибка фланцев/лапок (опц.)
4. Сборка: паз-шип лазер / болты (сварка только в кондукторе если нужна жёсткость)
5. Порошок 7016
6. Дерево: сиденье/столешница/полки
7. Контроль + упаковка плоско

## 6 китов (не 140 оснасток)

| Кит | Название | Детали металл | Дерево | Куда |
|-----|----------|---------------|--------|------|
| `SIDE2` | 2 боковины + спинка + сиденье | боковина L (зеркало), боковина R, спинка-лист (узор ЧПУ), опц. царга/стяжка | сиденье | стул, кресло, узкая скамья |
| `TRESTLE` | 2 опоры-треноги/А + столешница | опора A×2 (лазер+фланец), стяжки×2–3 | столешница | столы |
| `BENCH` | 2 боковины длинные + спинка-панели + сиденье | боковина×2, спинка сегменты или цельная, стяжки | сиденье длинное | скамьи, диван-скамьи |
| `LOUNGE` | Боковины глубокие + спинка + сиденье (+подлокотник лист) | боковина глубокая×2, спинка, подлокотник-лист опц. | сиденье, опц. подлокотник дерево | кресла, диваны |
| `SHELF` | 2 стойки-листа + полки | стойка с пазами×2, опц. задняя решётка/лазер | полки N | стеллажи |
| `BOX` | Бока+двери лазер + каркас полки | бок×2, дверца узор, полка-кронштейны | полки, столешница тумбы | тумбы |

### Зачем так

- **SIDE2:** Одна оснастка: меняется только DXF спинки и длина царг
- **TRESTLE:** Длина стола = длина дерева; металл один
- **BENCH:** Ряд длин: 120/160/180/200 — одна боковина, разные сиденья
- **LOUNGE:** Модуль 80: стык болтами без новой оснастки
- **SHELF:** Пазы лазером под полку — без сварки полок
- **BOX:** Дверца = смена DXF узора как у спинки стула

## Не делать в P0

- Поворотные пятки / сложные подшипники
- Складные шарниры как основной SKU
- Колёса в P0 (только опция)
- Гнутые трубы 3D без кондуктора
- Мягкая обивка фабрикой

## P0-HIT (запуск)

C-01, C-02, C-03, B-03, T-07, T-09, R-02, U-03

Стул Лофт/Орнамент/Гео → скамья 160 → стол 160/180 → стеллаж 3 полки → тумба 80.

## Узел стула (пример)

```
Лист 2 мм:
  · боковина L / R  — силуэт ножка+стойка спинки, фланец под сиденье
  · спинка          — прямоугольник с узором (паутина/дамаск/гео) — меняем DXF
  · царга           — полоса с отверстиями M6
Фанера 18:
  · сиденье         — 4 отверстия под болт
Сборка: боковины + спинка (болт/сварка в кондукторе) → порошок → сиденье.
```
