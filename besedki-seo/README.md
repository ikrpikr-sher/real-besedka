# Дизайнерские беседки — SEO-сайт

Собрано по гайду «Свой SEO-сайт под ключ с Claude Code PRO» (шаги 0–3). Полный контекст проекта — в `CLAUDE.md`.

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # проверка перед деплоем — должна пройти без ошибок
```

**Важно:** этот код написан в облачной песочнице без доступа к npm registry — `npm install` и `npm run build` ни разу не запускались. Открывая проект впервые, первым делом выполните `npm install && npm run build` и почините всё, что не соберётся (скорее всего — мелкие несостыковки типов).
