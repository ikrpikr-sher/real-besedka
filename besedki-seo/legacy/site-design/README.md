# Снимки дизайна сайта

Живой сайт сейчас — **vision-v1**. Старый экран лежит рядом и не удаляется.

| Снимок | Что это |
|---|---|
| `2026-10-06-pre-vision` | Главная и карточки **до** смены иерархии (спеки раньше каталога, H1 «Реал Беседки — …») |
| `2026-10-06-vision-v1` | Текущий дизайн после 6.10.2026 (герой-сцена, каталог сразу, тихие SEO-ссылки) |

Цены и `katalog.json` в снимках нет — их не трогаем.

## Вернуть старый вид на диск

Из `besedki-seo/`:

```bash
bash scripts/restore-site-design.sh 2026-10-06-pre-vision
```

Обратно к новому:

```bash
bash scripts/restore-site-design.sh 2026-10-06-vision-v1
```

Это только файлы в репозитории. На **прод** — отдельно `bash scripts/deploy.sh`.  
`data/home.json` в обычный деплой **не** входит: скрипт сам копирует его на сервер (не каталог, не цены).

На прод ничего не выкатываю, пока не скажете «верни старый на сайт».
