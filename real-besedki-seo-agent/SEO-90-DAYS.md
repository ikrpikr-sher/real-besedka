# SEO 90 дней — real-besedki.ru

Старт учёта: **2026-10-24**. Горизонт: до **2027-01-22**.  
Сайт: https://real-besedki.ru/ · ООО «Пулман» · бренд REAL БЕСЕДКИ.

Каждый будний прогон: `bash scripts/seo-weekday.sh` → `bash scripts/seo-daily-ship.sh` → backlog сверху.

## Правила

- P0 → P1 → P2. Сначала `health`.
- Не трогать: `priceFrom`, целый `katalog.json` на прод, массовые 100+ title, Директ, Авито.
- `seoDescription`: максимум **3 карточки за прогон** через `scripts/seo-daily-ship.sh`.
- Нет Вебмастера / GSC / Метрики — писать «Недостаточно данных», код и health всё равно проверять.

## Дни 1–30 (техника + сниппеты)

- Держать P0=0: форма, `tel:`, SSL, маршруты, sitemap.
- Пилот `seoDescription` 1–3/день по приоритету: открытые → остеклённые → лофт → мангал.
- Не откатывать прод-фиксы: noindex `/katalog/poisk`, 301 `/blog/category/sovety`, сборка в соседнем каталоге.
- Товарный OG (`og:type=product` + `og:image`), ContactPage, BreadcrumbList — уже на проде; не ломать деплоем старого дерева.

## Дни 31–60 (покрытие карточек)

- Закрыть пустые `seoDescription` у беседок (не хозблоки/перголы — они 301 на `/katalog`).
- Внутренние ссылки с коммерческих хабов на живые карточки.
- Повторно сверить sitemap (~2000 URL) с noindex-сиротами.

## Дни 61–90 (рост)

- Уникальный текст 800–1500 зн. только у ТОП-карточек, по 1–3 за прогон.
- Кейсы `/proekty` и отзывы — усиливать, не плодить тонкие URL.
- Off-page остаётся за владельцем: Вебмастер, GSC, цели Метрики, Яндекс Бизнес.

## Владелец (агент не сделает без кабинета)

1. Выгрузки Вебмастер + GSC + Метрика (цели форма / телефон).
2. Яндекс Бизнес / Google Business — фото объектов и отзывы.
