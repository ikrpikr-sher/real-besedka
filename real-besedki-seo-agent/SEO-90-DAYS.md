# SEO 90 дней — real-besedki.ru

Сайт: https://real-besedki.ru/ · ООО «Пулман» · цель: заявки (форма + звонок)  
Код: `besedki-seo/` · журнал: `SEO-AUDIT-REAL-BESEDKI.md`  
Метрики Вебмастера / GSC / Метрики в автопрогоне **нет** — не выдумывать позиции и трафик.

## Дни 1–30 — техника и сниппет карточки

- Ежедневный weekday: P0 → health → backlog сверху
- Пилот `seoDescription`: **до 3 карточек за прогон** (`scripts/seo-daily-ship.sh`)
- Товарный OG (`og:type=product` + `og:image`) в коде карточки, не через глобальный nginx rewrite
- Не трогать: целый `katalog.json`, `priceFrom`, массовые 100+ title, Директ, Авито
- Владелец: Cloudflare Proxied (LTE МО), цели Метрики «форма» + «телефон», Вебмастер / GSC

## Дни 31–60 — покрытие каталога и хабы

- Дозаполнить пустые `seoDescription` тем же пилотом (3/день)
- Хабы размеров / коммерческие URL уже в sitemap — не плодить дубли title
- Блог: человекочитаемые H1 категорий (уже в `CATEGORY_SEO`)
- Off-page: Яндекс Бизнес, Google Business, отзывы — только по факту кабинета

## Дни 61–90 — контент, который ведёт к заявке

- ТОП-20 карточек: уникальный текст 800–1500 знаков, если карточка без него
- Кейсы `/proekty` и отзывы — усиливать существующие разделы, не новый дизайн
- Повторный pagespeed по понедельникам; CWV править точечно
- Если появятся выгрузки Вебмастера / GSC / Метрики — сверка запросов с посадочными, без догадок

## Каждый прогон

```bash
bash scripts/seo-weekday.sh
bash scripts/seo-daily-ship.sh
```

Деплой кода: `cd besedki-seo && bash scripts/deploy.sh`  
Крупное изменение сайта: `bash scripts/site-release.sh "кратко" --push --deploy`
