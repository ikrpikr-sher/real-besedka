# On-page — карточка товара

URL: `/katalog/{category}/{slug}`

## Title (50–60 символов, ориентир)

```
{модель} {тип} из металла {размер} — от {priceFrom} ₽ | Real Besedki
```

**Пример:**
```
Беседка B-11 открытая из металла 3×3 м — от 230 000 ₽ | Real Besedki
```

## Description (140–160 символов)

```
Металлическая беседка {модель}: каркас 80×80, пол фанера, {особенность 1}, {особенность 2}. Производство и монтаж в Москве и МО. Расчёт за 15 минут.
```

**Правила:**
- Не выдумывать цену — только `priceFrom` из каталога
- Не писать «ДПК», если на карточке пол фанера
- Упоминать гео (Москва и МО) на коммерческих карточках
- Без переспама ключей

## H1

Один H1 = название из каталога (`title`), без дубля бренда в начале.

## Open Graph (этап 2)

| Поле | Источник |
|------|----------|
| og:title | = title |
| og:description | = description |
| og:image | hero-фото (`01_hero.jpg`) |
| og:url | canonical URL карточки |
| og:type | `product` |

## JSON-LD

Уже есть `Product` + `BreadcrumbList`. Проверить: цена = `priceFrom`, `availability`, изображение 200 OK.

## Alt галереи

`{title} — металлическая беседка {размер}, вид {front|left|right|hero}`
