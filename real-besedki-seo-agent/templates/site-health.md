# Полная проверка сайта — real-besedki.ru

Дата: ___________ · Режим: **только чтение** (правки — после «да»)  
Сайт: https://real-besedki.ru · Код: `besedki-seo/`

Цель проверки: клиент может **найти сайт в поиске**, **открыть**, **посмотреть товар/статью**, **оставить заявку** — на телефоне и десктопе.

---

## A. Доступность и работа сайта

- [ ] Главная `/` — 200, HTML отдаётся
- [ ] `/katalog` — список товаров
- [ ] 3 карточки `/katalog/{category}/{slug}` — 200
- [ ] `/katalog/poisk?q=B-51` и `q=В51` — поиск находит
- [ ] `/blog` + 1 статья — 200
- [ ] `/kontakty`, `/uslugi`, `/materialy` — 200
- [ ] Форма расчёта / заявка — поля видны, отправка не ломается (без тестового спама)
- [ ] Клик по телефону — `tel:` работает
- [ ] Меню: каталог, блог, контакты — пункты открываются
- [ ] 404 на несуществующий URL — страница ошибки, не белый экран
- [ ] HTTPS, редирект с http при необходимости

**CLI:** `python3 real-besedki-seo-agent/main.py report`

---

## B. Мобильные и все устройства

- [ ] Ширина ~375 (iPhone) — нет горизонтального скролла на главной и карточке
- [ ] Ширина ~768 (планшет) — сетка каталога читается
- [ ] Десктоп ~1280 — hero и каталог без наложений
- [ ] Кнопки CTA и телефон — тапабельны (≥44px ориентир)
- [ ] Мобильное меню открывается/закрывается
- [ ] Форма на мобилке — поля не обрезаны клавиатурой
- [ ] 3D / конфигуратор — не блокирует скролл на телефоне; есть fallback без WebGL

---

## C. Фото и видео

- [ ] Выборка 5 карточек: hero + галерея грузятся (не битые 404)
- [ ] Нет студийных/interior/`*_uzel` лишних в публичной галерее (только дворовые ракурсы)
- [ ] Alt у фото осмысленный (модель / размер / вид)
- [ ] Видео в блоге/главной: `preload="none"` или ленивая загрузка, не рвёт LCP
- [ ] Open Graph image на карточке (если этап 2 уже внедрён) — превью в Telegram/VK
- [ ] GLB/3D модель на карточке — 200 или скрыта корректно

---

## D. Статьи и контент

- [ ] `/blog` — список статей, обложки
- [ ] 2–3 свежие статьи — canonical, H1, внутренние ссылки
- [ ] Нет массовых ссылок на `/proekty` (должны быть `/katalog/...`)
- [ ] Категории/теги блога — H1 человекочитаемый, не slug
- [ ] FAQ в статьях — schema FAQPage (если есть блок FAQ)
- [ ] План контента: 2–4 статьи/мес. под заявку (не ради объёма)

---

## E. Как сайт виден клиенту (UX / доверие)

- [ ] С первой экрана понятно: металлические беседки, Москва/МО, «под ключ»
- [ ] Цена «от … ₽» на карточке совпадает с оффером (не выдумывать)
- [ ] Пол/каркас в текстах: **фанера**, **80×80** — без противоречий (ДПК только если опция)
- [ ] Контакты / NAP совпадают с `site.json` и карточками организаций
- [ ] Отзывы / соцдоказательства — если есть блок, ссылки живые
- [ ] Шаринг ссылки: title + description адекватные в сниппете мессенджера
