# SEO backlog — план работ этапа 2

Генерируется CLI:

```bash
python3 real-besedki-seo-agent/main.py backlog
python3 real-besedki-seo-agent/main.py backlog --no-live
```

Выход: `logs/YYYY-MM-DD_backlog.md`

Приоритеты:
- **P1** — влияет на заявки в ближайшие 1–3 месяца
- **P2** — усиливает, но не блокирует
- **info** — статус прода, не задача

Правка сайта — только после явного «да» на строку backlog.
